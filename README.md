Koi Current — a 2D canvas arcade game in which a glowing koi swims upstream through a dusk river: steer with arrows, WASD or the pointer, collect pearls and fireflies into a combo, dodge rocks, drifting logs, telegraphed heron strikes and pulling whirlpools across 8 quickening levels, and reach the Lantern Gate at 1000 m before 3 hits end the run, with synthesised WebAudio sounds and a full title, pause, win and game-over flow.

## Run it

```sh
node serve.ts
```
